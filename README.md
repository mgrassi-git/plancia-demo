# Quota — dimostrazione

Versione pubblica e **con dati di esempio** di Quota: portafoglio, grafico, lettura del clima di
mercato, radar su 129 strumenti e prove automatiche di trading.

👉 **https://mgrassi-git.github.io/plancia-demo/**

- Il portafoglio mostrato è inventato (quote e importi); prezzi, radar, notizie e prove automatiche sono reali,
  fermi al giorno della pubblicazione.
- Non c'è nessun server dietro: la pagina legge i json in `data/` e tiene lo stato nel browser.
  Niente ordini, niente collegamenti a un broker.
- Il codice sorgente sta in un repo separato. Questa cartella è solo il prodotto della build.
